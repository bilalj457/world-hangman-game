# 🌍 World Hangman Game

## About

World Hangman is a beginner-friendly Python word guessing game. The computer randomly selects a country, and the player tries to guess its name one letter at a time.

The player has six wrong guesses before the game ends.

I created this project to practise Python fundamentals and improve my problem-solving skills.

## Features

- Random country selection
- Letter-by-letter guessing
- Six chances for wrong guesses
- Visual Hangman drawings
- Input validation
- Prevention of repeated guesses
- Win and loss counter
- Option to play again

## Requirements

- Python 3
- No external libraries required

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal inside the project folder.
4. Run the following command:

   `python world_hangman.py`

   If needed, use `python3 world_hangman.py` instead.

## How to Play

1. Run the program.
2. The game selects a random country.
3. Enter one letter at a time.
4. Correct guesses reveal letters in the country name.
5. Incorrect guesses add a part to the Hangman drawing.
6. Guess the country before you run out of chances.
7. Choose whether to play another round.
